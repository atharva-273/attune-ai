# Fidelity Checklist (Per Screen)

- Frame size and safe area are exact to target mobile node
- Position and spacing values match inspect panel values
- Typography family, size, weight, line height, and letter spacing match
- Color, gradients, opacity, radii, and shadows match
- Icon/image dimensions and anchor positions match
- CTA and interactive state visuals match (default, pressed, disabled if applicable)
- Screen includes traceability attributes (`data-flow-id`, `data-screen-id`, `data-figma-node-id`)

## Motion Checklist

- Trigger points align with user interaction or route transition
- Duration, delay, easing, and sequence align with spec
- No jank when rapidly navigating between screens
- Enter/exit choreography remains deterministic
